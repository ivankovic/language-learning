### Content translation coverage (`/goal`: full translation of all content to all supported languages)

UI text is done for all 6 languages. Vocab + lesson prose/exercise translation is the cross-product tail: 5 target-language courses × 4 other known languages each (English excluded — it's already the base/default; a course's own language excluded — N/A), ~1000 words + ~14-25 lessons per pair = 20 pairs total. Translation is always **term-based** (from the target-language word, using the English gloss only to disambiguate polysemy), never gloss-based — gloss-to-gloss translation reintroduces the exact polysemy bugs (bank/spring/light picking the wrong sense) that term-collision dedup used to catch during content authoring, except with no tripwire to catch it. Each pair is completed fully (vocab + lessons + titleByLang for course/units/decks) before moving to the next, verified with a loader-test run + one browser spot-check per pair, and checked off here immediately on completion so a mid-goal context compaction doesn't lose track.
