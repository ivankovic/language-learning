# Content Staging

This directory holds content generated by the (future) content-generation
pipeline described in `SPECS.md`'s "Content Sourcing & Authoring Pipeline"
section, before it's reviewed and promoted into `src/content/<lang>/`.

Nothing here ships to production — it's read only by the dev-only review
route at `src/dev/content-review/ContentReviewRoute.tsx`, which is excluded
from production builds via `import.meta.env.DEV`.

## Pipeline

1. **Course outline** — per-language config: units, CEFR level, topics, grammar points in order.
2. **Generation** — content drafted against the schema in `src/types/content.ts`.
3. **Staging** — generated output lands here, in `<lang>/` subfolders, mirroring the shape of `src/content/it/`.
4. **Review** — `bun run dev`, visit `/#/dev/content-review`, review staged lessons/decks rendered as the app would show them.
5. **Promotion** — approved content is assigned a permanent stable `id` and moved into `src/content/<lang>/`. IDs are never reassigned after this point.

Empty for now — Phase 1 shipped with hand-authored seed content directly in
`src/content/it/` rather than running this pipeline.
